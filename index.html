Start here: five steps to a defensible accessibility decision

Use this workspace to document what the vendor claims, what was tested, what people experienced, and what needs follow-up. The application does not certify compliance.

  1. Define your scope in Form A, including essential tasks and integrations.
  2. Review the ACR manually; record vendor claims as unverified, and note any missing evidence.
  3. Plan and observe tasks in Form B with appropriate assistive technology and disabled participants.
  4. Record AI risks and fixes in Forms C and D. Keep proposals separate from findings.
  5. Decide and document limits in Form E; export a draft report for human approval.

New to this? Choose “Load clearly labeled fictional example” in Overview to practice without using real data. No API key, account, or payment is needed to use any of the five forms.

Evaluation workspace

This prototype operationalizes the toolkit's seven stages: (1) scope, (2) review vendor claims, (3) technical checks, (4) task tests, (5) user participation, (6) AI risk review, and (7) decide and monitor.

Evidence rule: Keep technical findings, task outcomes, participant perspectives, and AI risks separate. A successful task does not cancel a standards violation; a passing technical check does not erase a task failure.

Use fictional participant codes, not names or medical information. Avoid entering sensitive records on shared devices.

Optional AI document analysis — run it on your own computer

The free toolkit does not send information to an AI provider. If you want an assistant to analyze an Accessibility Conformance Report (ACR), use the separate, downloadable local AI Agent supplied alongside this toolkit. You control its installation and provide an API key from your own account; the toolkit author is not billed.

  1. Download the Optional Local AI Agent ZIP from the toolkit distribution page or project package.
  2. Read its README and install Python dependencies on your own Windows, macOS, or Linux computer.
  3. Configure your own OpenAI API key in your terminal. Do not enter any API key on this public site.
  4. Open the local agent at http://127.0.0.1:8765, upload an authorized ACR, verify AI claims against the source, and use its Forms A–E.
  5. Export local findings as a draft report or JSON. Keep vendor claims, proposed tests, verified results, and participant perspectives distinct.

Costs: The public toolkit incurs no OpenAI API usage. Optional local AI requests are billed to the account associated with the user's own key, even if the user has a ChatGPT subscription. No live AI analysis is included in this free website.

Privacy: The local agent sends extracted ACR text to OpenAI only when its user explicitly requests AI analysis. Do not submit confidential documents without authorization.
